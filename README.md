# ai-engineering-portfolio

A structured portfolio of enterprise-grade AI engineering projects — built to go beyond tutorials and cover the parts of LLM systems that matter in production: retrieval architecture, agent orchestration, security, evaluation, and observability.

> 3+ years shipping GenAI systems at enterprise scale. This portfolio documents the patterns, tools, and hard-won lessons from that work — and pushes into areas most engineers haven't explored yet.

---

## What's in this repo?

Smaller experiments, reference notebooks, and cross-cutting utilities that support the standalone projects below.

| Folder | Description |
|---|---|
| [`rag/`](./rag/) | RAG experiments — chunking strategies, retrieval tuning, embedding comparisons |
| [`agents/`](./agents/) | Agent prototypes — tool use, ReAct patterns, memory experiments |
| [`eval/`](./eval/) | Evaluation notebooks — RAGAS, custom metrics, benchmark comparisons |
| [`security/`](./security/) | LLM security research — prompt injection demos, OWASP LLM notes |
| [`notebooks/`](./notebooks/) | Standalone Jupyter notebooks — deep dives and explorations |
